# Despliegue de tu portafolio de datos

Has creado gráficos increíbles y dashboards interactivos. El último paso es sacarlos de tu computadora y ponerlos en el mundo para que empleadores y clientes puedan verlos.

## Opciones de Hosting Moderno

### 1. Vercel / Netlify (Front-end)
Ideal para dashboards creados con React, Vue o HTML puro.
- **Costo:** Gratis para proyectos personales.
- **Ventaja:** Conexión directa con GitHub y despliegue automático.

### 2. GitHub Pages
Perfecto para portafolios estáticos. Solo subes tu código a un repositorio y habilitas la opción de Pages en la configuración.

### 3. Streamlit Cloud / Hugging Face Spaces
Específicos para aplicaciones de Python (Módulo 3). Permiten desplegar apps pesadas de datos sin configurar servidores.

## Tu Portafolio Profesional
Un buen portafolio de visualización debe incluir:
- **El Problema:** ¿Qué pregunta de negocio estás resolviendo?
- **La Herramienta:** ¿Por qué elegiste D3 sobre Plotly?
- **La Solución:** El dashboard interactivo embebido.
- **El Código:** Link a tu repositorio de GitHub para demostrar calidad técnica.
