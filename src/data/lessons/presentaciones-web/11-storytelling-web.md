# Scrolltelling: Narrativa guiada por datos

El *Scrolltelling* es una técnica de diseño web donde la visualización de datos cambia y se anima a medida que el usuario hace scroll hacia abajo. Es la forma definitiva de contar historias con datos en la red.

## ¿Por qué usar Scrolltelling?
- **Engagement:** Mantiene al usuario enganchado en una narrativa lineal.
- **Contexto:** Permite explicar partes específicas de un gráfico complejo paso a paso.
- **Memorabilidad:** La interactividad táctil ayuda a retener mejor la información.

## Elementos del Scrolltelling
1. **El Fondo (Gráfico):** Se mantiene fijo (`sticky`) mientras el texto se mueve.
2. **Los Disparadores (Triggers):** Puntos en el scroll que activan cambios en el gráfico (cambiar colores, filtrar datos, mover la cámara).
3. **El Texto (Narrativa):** Paneles de texto que flotan sobre el gráfico dando contexto.

---

### Librerías recomendadas
- **Scrollama.js:** La librería más ligera y fácil de usar para manejar eventos de scroll.
- **GSAP (ScrollTrigger):** Para animaciones ultra-fluidas y profesionales.
- **D3 + Waypoints:** La combinación clásica para proyectos de alto nivel.
